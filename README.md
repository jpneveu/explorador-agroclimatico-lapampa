# La Pampa | Explorador Agroclimático

Prototipo educativo para la exploración de información agroclimática de la provincia de La Pampa, Argentina (2020–2025).

**Ver el explorador:** https://jpneveu.github.io/explorador-agroclimatico-lapampa/

- `index.html`: tablero interactivo autónomo (funciona también sin conexión).
- `datos_agroclimaticos_lapampa.csv`: datos procesados (provincia y 22 departamentos, mensuales y anuales).
- `fuentes_y_metodologia.md`: fuentes, procesamiento, controles y limitaciones.

Fuentes: CHIRPS v3.0 y CHIRTS-ERA5 (Climate Hazards Center, UCSB), límites GADM 4.1. Procesado con herramientas del CGIAR Climate Data Hub.
